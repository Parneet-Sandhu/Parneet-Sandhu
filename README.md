## 🧠 About Me

I'm interested in the entire process: finding the problem, understanding the data, building the model, and turning the idea into something people can actually use. My projects have taken me from healthcare and agriculture to geospatial analysis and biotechnology — because I like exploring what AI can do outside the usual benchmark-and-dashboard bubble.

Different problems. Different domains. Same obsession: building intelligent things.

- 🔭 Experienced in production Generative AI — RAG chatbots, conversational AI (Cardekho Group)
- 🌱 Currently pursuing M.Tech in Cyber Security
- ⚡ Fun fact: reduced token costs by 40% while maintaining 90% accuracy in a RAG system
